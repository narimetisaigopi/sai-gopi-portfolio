# Sai Gopi Narimeti — Portfolio

A responsive, dark-themed portfolio built with plain HTML, CSS, and JavaScript. It is designed for GitHub Pages and has no build step or framework dependency.

## Included

- Responsive layout for desktop, tablet, and mobile
- Project filters: All, Office, Freelance, Websites
- Android, iOS, and website links supplied by Sai Gopi
- Professional introduction and technology stack
- No invented project metrics or project-specific responsibilities

## Before publishing

1. Open `index.html`.
2. Replace the LinkedIn link (`https://www.linkedin.com/`) with your actual profile URL.
3. Replace `YOUR_EMAIL@example.com` in `script.js` and the related button label/note in `index.html` with your real email.
4. Review project labels and links. The portfolio intentionally avoids claiming specific responsibilities for individual projects.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `sai-gopi-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub Pages finishes deploying, the site URL will appear in the Pages settings. For a repository named `YOUR-USERNAME.github.io`, the URL is usually `https://YOUR-USERNAME.github.io/`; for another repository, it is usually `https://YOUR-USERNAME.github.io/sai-gopi-portfolio/`.

## Editing projects

Project cards are in `index.html`. Each card has a `data-category` value:
- `office`
- `freelance`
- `web`

When adding or removing cards, update the filter counts in the filter bar. The counts currently reflect the supplied list: 3 office entries, 9 freelance entries, and 3 website entries. YestoFix includes customer and partner Android links and the iOS search link provided.
